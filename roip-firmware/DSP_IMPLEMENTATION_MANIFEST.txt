ALGORITHMS
==========

Biquad IIR Filter:
  - Type: Direct Form II (high efficiency)
  - Order: 2nd order (40dB/octave rolloff)
  - Stability: Numerically stable
  - Cost: 5 MACs + 4 additions per sample

AGC:
  - Attack: 5ms (fast response to peaks)
  - Release: 50ms (smooth recovery)
  - Target: 0.7 (-2.5dB default)
  - Gain: -20dB to +40dB range

Compressor:
  - Attack: 10ms
  - Release: 100ms
  - Threshold: -20dB
  - Ratio: 4:1
  - Knee: 6dB soft knee

VAD:
  - Energy threshold: -40dB
  - Hangover: 37.5ms
  - Smoothing: 0.9/0.1 coefficients
  - Hysteresis: Prevents chatter

Gate:
  - Attack: Immediate
  - Hold: 100ms minimum
  - Threshold: -50dB
  - Decay: 100ms smooth

INTEGRATION
===========

Into AudioLoop:
  1. Create DSPProcessor instance
  2. Call initialize(8000)
  3. In audio loop: dsp.process(input, output, 160)
  4. Monitor: dsp.getRMSLevel(), dsp.getVoiceActive()

With I2S:
  - Receives int16_t samples from I2S
  - Processes through complete chain
  - Outputs conditioned audio

With Codec:
  - TX: DSP -> Codec -> Network
  - RX: Network -> Decoder -> DSP -> Output

With Network (VAD):
  - Only transmit when dsp.getVoiceActive() = true
  - Saves ~50% bandwidth
